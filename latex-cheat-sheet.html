LaTeX cheat sheet for Word equations

You do not need to learn LaTeX to use MathToWord, but knowing a few commands helps you read what the AI writes and fix small mistakes quickly. Below are the commands students use most.

Basic building blocks

You writeYou get
\frac{a}{b}Fraction a over b
\sqrt{x}Square root of x
x^2 and x_1Power and subscript
\int_0^1 f(x)\,dxDefinite integral
\sum_{n=1}^{\infty}Summation to infinity
\lim_{x\to 0}Limit

Symbols and Greek letters

Use \alpha, \beta, \theta, \pi, \sigma and \omega for Greek letters. For comparisons use \leq, \geq, \neq and \approx. For signs use \pm, \times, \cdot and \infty.

Brackets and spacing

Write \left( ... \right) so brackets grow with tall content such as fractions. Use \quad for a wide space and \, for a thin space before dx.

Matrices

A matrix is written as \begin{bmatrix} a & b \\ c & d \end{bmatrix}. Use & between columns and \\ to start a new row.

Common mistakes

  • A missing closing bracket { } is the most common reason for a red error.
  • Forgetting the backslash turns a command into plain text.
  • Mixing normal words inside an equation needs \text{ like this }.
