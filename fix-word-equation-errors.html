Fix Word equation errors when pasting LaTeX

If your equation looks wrong in Word, the cause is usually simple. Find your problem below and follow the fix.

Problem 1: Word shows backslashes and code

You pasted into normal text. Word only understands LaTeX inside an equation box. Press Alt + = first, then paste and press Enter. Or use the Download Word file button, which builds real equations for you.

Problem 2: The result is aligned to the right or looks messy

Word treats a line as an equation or as text based on how it was inserted. Delete the messy lines, then use Copy for Word or the .docx download to get clean paragraphs and centered equations.

Problem 3: Headings and bold text are lost

This happens when you select the AI text with the mouse. Use the Copy button under the AI answer so Markdown marks (## and **) come with it. MathToWord then turns them into real headings and bold text.

Problem 4: A red error appears in the preview

The LaTeX itself is invalid, often because of a missing bracket. Ask the AI to rewrite just that equation, or see the LaTeX cheat sheet to fix it yourself.

Problem 5: Nothing happens when I press Copy for Word

Some browsers block rich clipboard access. Try Chrome or Edge, or use Download Word file.

Problem 6: Old Word version

Equations in the .docx work best in Word 2016, 2019, 2021 and Microsoft 365. Older versions may not show every symbol. Google Docs and LibreOffice can also open the file.
